# Marcas dos clientes

Cada cliente tem uma ficha em `marcas/<cliente>.md`, no formato de `marcas/_modelo.md`.

## Quando a ficha não existe

1. Pergunte se o usuário tem manual de marca, logo ou site. Use o que ele der.
2. Se houver site: abra-o, tire screenshot e leia o CSS computado — cor de fundo, texto, botões e links,
   fontes (`font-family`), raio dos botões. Baixe o logo (SVG de preferência) do próprio site.
3. Monte a ficha a partir do modelo com o que foi **medido**, marcando a origem de cada valor. Não invente
   cores "que combinam".
4. Mostre a ficha ao usuário e peça confirmação antes de usá-la como definitiva. Até lá, marque
   `Status: rascunho`.
5. Sem site e sem material: use a paleta do estilo escolhido e avise que a marca ficou pendente.
