# Estilos (DESIGN.md)

Esta pasta não vem preenchida: os DESIGN.md são da [Refero Styles](https://styles.refero.design) e não são
redistribuídos aqui.

1. Abra o estilo em styles.refero.design e baixe o DESIGN.md.
2. Salve aqui como `<id>.md`, usando o id do `catalogo.md` (ex.: `apple.md`, `linear.md`, `ramp.md`).
3. Estilo novo, fora do catálogo: salve o arquivo e adicione uma linha em `catalogo.md`.

Sem o arquivo de um estilo, o Atelier usa a linha do catálogo como direção e as regras da casa.
